# Machine and power audit: GTNH 2.8.1

Sources: GT5-Unofficial 5.09.51.476, Railcraft 9.16.33, ForestryMC 4.10.17, MagicBees 2.9.4-GTNH, Binnie 2.5.23, Mobs-Info 0.5.6-GTNH, Crops-plus-plus 1.8.11 (manifest only: CropsNH absent). 2.9 reference: the code at 1085da11.

How to read this list:

- "Our code" names the file, and the function or table where the row needs one; a Machine table row is the table entry of its name, a Power sources row the source of its id, a Pipeline tables row the named entry. "2.9 behaviour" is what our code does today (the curated table, the modules, the data files), which was transcribed from GT5-Unofficial 5.09.54.x. "2.8.1 source" is the line in the mod at its 2.8.1 manifest tag that decides the same thing.
- GT5-Unofficial paths are relative to `src/main/java/` in `GTNewHorizons/GT5-Unofficial@5.09.51.476`. `GT5U@` below is short for that repo.
- Many GT++ machines were rewritten as new `gregtech` classes in 5.09.54 and kept as `*Legacy` fossils under the same name. Our table follows the rewrite; 2.8.1 runs the old GT++ class, so the comparison is against that class.
- A machine whose controller does not exist in 2.8.1 under the name our table keys on is `absent in 2.8.1`. The evidence for absence is the controller registration block in the mod source (no registration under that name). No recipe, machine or handler name in the local 2.8.1 dataset normalizes to any absent machine's key.
- Java float literals (`1F / 2.2F`) are widened to double with float error; the 5.09.54 rewrites mostly pass doubles. That is listed once under Shared rules, not per machine.
- "2.8.1 source" starts with one of: a `<Repo>@<tag> <path>.java:<line>` citation; `each row under <group>` for a row that sums up a group; `GTNH 2.8.1 manifest:` where the pack's mod list decides it; or the repo file that holds the 2.8.1 data or the separate check (`src/lib/.../data/2.8.1/...`, `docs/audits/...`).
- "Outcome" is what the planner does about the row now: the fix or the check, the test that pins it, and the source lines it rests on. 2.9 follows GT5-Unofficial 5.09.54.205, so an outcome can also name a 2.9 correction. An empty cell means no fix or check touched the row since the audit.

## Fix rules

- A fix to a pipeline table (machine-wiki-stats.mjs, machine-configs.mjs, sparge-byproducts.mjs, eec-drops.mjs) keys on the export's `gtnhVersion` at normalize time, and the 2.8.1 dataset is then rebuilt and reinstalled.
- A machine table, module or power fix is a 2.8.1 override chosen by the plan's game version (`forVersion` and the override maps); the 2.9 entries stay as they are.
- `oracle export` rows are settled by checking the 2.8.1 oracle export files in `src/lib/machines/data/2.8.1/`; `hand read` rows by reading the 2.8.1 Java named in the row.
